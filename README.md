# Biblioteca Digital — Unidad didáctica 3

Dos bibliotecas de recursos independientes (HTML + CSS + JS vanilla), basadas en la plantilla de TEUX_UD2.

## Estructura

```
BIbliotecaDigital/
├── Audiovisual/   Biblioteca de recursos audiovisuales (vídeos, charlas, pódcasts, galerías, demos)
│   ├── index.html
│   ├── css/styles.css
│   └── js/{data.js, app.js}
└── Teorico/       Biblioteca de recursos teóricos (libros, artículos, casos, bases de datos)
    ├── index.html
    ├── css/styles.css
    └── js/{data.js, app.js}
```

## Cómo usarlas

Abre el `index.html` de cada carpeta directamente en el navegador o sírvelo con cualquier servidor estático. Para añadir o editar recursos, modifica el array `RESOURCES` en el `js/data.js` correspondiente.
